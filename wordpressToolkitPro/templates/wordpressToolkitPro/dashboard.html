Migrate a site to this server

Moves one WordPress site from DirectAdmin (or any host) onto a website you already created in CyberPanel. The Toolkit builds the new site next to the old one and only switches when everything is ready, so a failed run changes nothing.

  1. In DirectAdmin, create a backup of the site. The archive must contain wp-config.php and one database dump (.sql or .sql.gz), and only one WordPress.
  2. Create the website in CyberPanel (same domain, or a test domain).
  3. Choose the archive below, start the migration and check the result before you change DNS.

From a server folder Best for big sites

Copy the archive to /home/wptoolkit-migrations/incoming/ with SFTP or scp, then pick it here. No browser upload limits.

Upload from this browser

ZIP, TAR, TAR.GZ or TGZ up to 2 GB. Large uploads can be cut off by the web server, so use the server folder for anything over a few hundred MB.

The Toolkit creates a dedicated database, imports the dump, updates the database login and the site address, and replaces the old .htaccess with a clean one. Test the site with your hosts file before pointing DNS here.
