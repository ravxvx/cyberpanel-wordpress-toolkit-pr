Maintenance, security and cleanup

Maintenance: visitors get a temporary "unavailable" page (HTTP 503) while you work. File integrity: compares WordPress core and wordpress.org plugin files with the official releases (finds modified files, e.g. after a break-in). Clean database: deletes post revisions, spam and trashed comments and expired transients, then optimizes tables (a backup is made first).

Error logs

"Enable debug" turns on WordPress debug logging (errors are written to wp-content/debug.log, never shown on the page, and the file is blocked from the web). Turn it off when finished.
